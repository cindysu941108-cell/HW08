## 程式用途
本程式為聚餐費用試算器，主要用於處理含有空白與貨幣符號的原始字串資料，進行清理與型別轉換後，計算 10% 服務費、扣除折價券之應付總額、每人分攤費用，並透過布林運算判斷是否超過每人預算。如何在 Colab 開啟與執行：只需將 `.ipynb` 筆記本上傳至 Google Colab，由上往下依序執行各儲存格即可。

## 三組測試結果摘要
- **測試一**（4人，折價券100元）：應付總額 1,220.00 元 / 每人費用 305.00 元 / 超過預算：True
- **測試二**（5人，折價券100元）：應付總額 1,220.00 元 / 每人費用 244.00 元 / 超過預算：False
- **測試三**（4人，折價券220元）：應付總額 1,100.00 元 / 每人費用 275.00 元 / 超過預算：False

## 問題回答
1. **為什麼 "4" 要先轉成數字，才能用於本題的分攤計算？**
   - 因為 `"4"` 在 Python 中是字串（str），字串無法直接參與數學除法運算（例如總金額除以字串會發生型別錯誤），必須先使用 `int()` 轉換成整數後才能計算每人費用。
2. **如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**
   - 如果先扣折價券（1,200 - 100 = 1,100），再計算 10% 服務費（1,100 × 1.1 = 1,210），應付總額會變成 1,210 元。這和規定的 1,220 元不同，因為服務費計算的基礎（基底）改變了，而一般餐廳規定服務費應以折扣前的原始餐費來計算。
